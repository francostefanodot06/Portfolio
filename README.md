🛠️ Tecnologías Utilizadas

Este portafolio está construido desde cero, sin frameworks pesados, para mantenerlo ligero, rápido y fácil de mantener.

HTML5 y CSS3: Marcado semántico y diseño responsivo.

Vanilla JavaScript: Para la interactividad y manipulación del DOM.

i18n Personalizado (i18n.js): Un script de internacionalización creado a medida para alternar entre inglés y español de forma fluida.

Hosting / CI/CD: Desplegado automáticamente usando GitHub Pages.

💻 Proyectos Destacados en el Sitio

Puck (AI SysAdmin): Un middleware construido con Python y FastAPI que actúa como un SRE virtual usando LLMs locales (Ollama) para gestionar alertas y proponer comandos de bash para la resolución de incidentes.

Homelab: Mi infraestructura auto-alojada corriendo sobre Proxmox VE, demostrando conocimientos en IaC, virtualización y gestión de servicios (Docker, LXC).

Proyectos Académicos (UTN): Un repositorio centralizado para mis trabajos de la facultad (POO en Java, Bases de Datos Relacionales, Estructuras de Datos).
